OpenCart Manual Testing Project
Objective: End-to-end manual functional testing executed on the OpenCart e-commerce platform (demo.opencart.com).
Documentation: All QA artifacts are fully consolidated within the master file Manual Testing Qa Project.xlsx.
Core Artifacts: Includes FRS requirements, Test Scenarios, Test Cases, Bug Reports, RTM, and a Test Summary report.
Methodology: Applied black-box testing techniques, including Boundary Value Analysis, Equivalence Partitioning, and Negative Testing.
Coverage: 100% requirements-to-test traceability mapping core modules like Registration, Login, Cart, and Checkout.
